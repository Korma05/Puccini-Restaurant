# Puccini Restaurant — Newcastle upon Tyne

A premium, responsive React/Vite restaurant website built from the supplied Puccini brief, restaurant photographs and current two-page food menu.

## Included
- React + Vite
- Responsive mobile-first layout
- Premium Italian restaurant visual system
- Menu categories populated from the supplied menu PDF
- Download/view full printed menu
- Real restaurant photos supplied with the project
- Gallery lightbox
- Click-to-call phone number
- Google Maps directions link
- Facebook link supplied in the brief
- Accessibility-minded semantic structure and keyboard-friendly controls
- SEO metadata and local restaurant copy
- No invented booking/order platform links

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

The supplied menu PDF is in `public/Puccini-Food-Menu.pdf`.
